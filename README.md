# Alurabooks
Projeto feito durante o curso de responsividade da Alura.

Este é um projeto de criação da interface visual do **AluraBooks**, uma plataforma de livros digitais focada em cursos e e-books sobre tecnologia e desenvolvimento. O layout foi feito usando apenas **HTML** e **CSS**, com um design responsivo para proporcionar uma experiência de usuário fluida em dispositivos móveis, tablets e desktops. 📱💻

##  🛠️ Tecnologias Utilizadas 🛠

- **HTML**: Estruturação do conteúdo da página, criando a hierarquia de informações de forma semântica.
- **CSS**: Estilização e design da página, além de tornar a interface responsiva e agradável para o usuário.

##  ✨Funcionalidades 

- **Menu de navegação**: Um menu com categorias de livros, favoritos e opções de perfil.
- **Pesquisa de livros**: Barra de pesquisa para encontrar livros rapidamente.
- **Carrossel de lançamentos**: Exibição de livros novos e populares através de um slider interativo.
- **Favoritos e compras**: Ícones de interação com carrinho de compras e favoritos.
- **Rodapé informativo**: Links de diversas plataformas educacionais e comunidade Alura.

## Design Responsivo 📱💻

A página foi construída para ser totalmente responsiva, ou seja, ela se adapta a diferentes tamanhos de tela, oferecendo uma ótima experiência tanto em dispositivos móveis quanto em desktops.


## Recursos Adicionais 

- **Swiper**: Utilizado para criar os sliders/carrosséis interativos na seção de novos lançamentos e mais vendidos.
- **Reset CSS**: Garantindo que a página tenha um estilo consistente em diferentes navegadores.
